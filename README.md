# dcit26-compilation

A compilation of Flutter and Dart laboratory activities for DCIT 26 - Application Development and Emerging Technologies.

## Labs

- Lab 1 - Hello World: lab1_hello_world/
- Lab 2 - Student Profile: lab2_student_profile/
- Lab 3 - Input and List: lab3_input_list/
- Lab 4 - Modal and Scrolling: lab4_modal/
- Lab 5 - Navigation: lab5_navigation/
- Lab 6 - Passing Product Data: lab6_products/
- Lab 7 - Networking: lab7_networking/

Lab 8 is this repository itself (Git and GitHub).

## How to run

Each lab folder is its own Flutter project.

1. One time only: run setup_all.bat (Windows) or setup_all.sh (macOS/Linux) from this folder.
2. Open a lab folder in a terminal and run flutter run -d chrome.
